# Foursday Codex 插件

这个插件把本机 Foursday 工作分身的只读控制入口带入 Codex。它不会替代后台服务，也不会因为安装插件而开启钉钉发送或工作计划执行。

## 可以查看什么

| 工具 | 用途 | 是否产生外部动作 |
|---|---|---|
| `get_status` | 查看健康、暂停状态和待处理数量 | 否 |
| `show_status_panel` | 以内嵌卡片展示同一份状态 | 否 |
| `list_pending_drafts` | 查看等待人工审核的消息与草稿 | 否 |
| `list_work_plans` | 查看最近工作计划及步骤状态 | 否 |
| `list_takeovers` | 查看需要人工接管或核对的计划 | 否 |
| `list_capabilities` | 查看当前全局开关与项目能力 | 否 |
| `get_weekly_plan` | 查看本周剩余目标和按确认证据排序的受控委托建议 | 否 |
| `open_admin_console` | 返回本机完整管理台入口 | 否 |

## 运行条件

1. Foursday 管理服务在本机 `127.0.0.1:9465` 运行。
2. 管理只读令牌已保存在 macOS 钥匙串服务 `foursday-production` 的 `admin-read-token` 账号中；升级中的旧环境也可暂时使用 `ai-employee-production`。
3. Node.js 版本不低于 22.5。

插件默认从钥匙串读取只读令牌，只访问回环地址。它不会读取管理写入令牌。周计划工具只请求专用 `/api/weekly-plan` 有界接口，不读取包含项目目标、记忆正文和计划步骤的完整驾驶舱。其他机器复用时，可以设置 `AI_EMPLOYEE_ADMIN_URL`，但地址仍必须是本机 HTTP 回环地址。

`get_weekly_plan` 需要 0.6.0 或更新的本机服务。新版插件连接旧服务时会明确返回 `available: false`，不会把缺失数据解释为本周零缺口或目标已完成；应先升级服务并重新核验。

## 安装

仓库提供一个可由 Codex 识别的本地插件市场，但不会自动修改个人配置。先在仓库根目录运行只读预检：

```bash
npm run codex:verify
```

确认输出中的 `valid` 和 `readOnly` 都是 `true`、`personalConfigurationWrite` 是 `false` 后，再选择一种市场来源。

从公开仓库安装：

```bash
codex plugin marketplace add ruiwang20010702/foursday --ref <40位已审核提交SHA>
codex plugin add foursday@foursday-local
```

从本地代码安装：

```bash
codex plugin marketplace add <仓库绝对路径>
codex plugin add foursday@foursday-local
```

安装后重启 Codex，并新建任务测试。安装插件不会启动管理服务，也不会开启钉钉发送或计划执行。

### 从旧插件身份迁移

`0.3.0` 之前安装的内部身份为 `ai-employee@ai-employee-local`。迁移只改变 Codex 插件注册，不修改后台服务、数据库、钥匙串或发送开关：

```bash
codex plugin remove ai-employee@ai-employee-local
codex plugin marketplace remove ai-employee-local
codex plugin marketplace add ruiwang20010702/foursday --ref <40位已审核提交SHA>
codex plugin add foursday@foursday-local
```

完成后重启 Codex，并用只读状态工具回验。旧插件移除失败时停止迁移，不要手工删除 Codex 缓存目录。

## 升级与卸载

公开仓库版本升级：

```bash
codex plugin marketplace upgrade foursday-local
codex plugin add foursday@foursday-local
```

本地版本更新后重新运行 `npm run codex:verify`，再执行相同的 `codex plugin add`。开发中的缓存刷新使用 Codex 官方插件工具维护版本后缀，不手工修改个人市场文件。

卸载插件：

```bash
codex plugin remove foursday@foursday-local
```

确认不再使用该仓库中的任何插件后，才移除市场来源：

```bash
codex plugin marketplace remove foursday-local
```

卸载只影响 Codex 插件，不会停止 Foursday 后台服务；后台启停继续使用项目原有的受控服务命令。
