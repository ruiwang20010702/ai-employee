# AI 员工 Codex 入口

使用本插件提供的只读 MCP 工具获取当前状态，不根据历史对话或模型记忆猜测运行结果。

## 使用顺序

1. 询问整体状态时先调用 `get_status`。
2. 询问待回复内容时调用 `list_pending_drafts`，明确区分原消息、建议草稿、风险和原因。
3. 询问方案、执行或接管时调用 `list_work_plans` 或 `list_takeovers`。
4. 询问“能做什么”时调用 `list_capabilities`，只描述当前配置和授权。
5. 需要人工审批、修改、暂停或处理异常时调用 `open_admin_console`，让负责人进入本机管理台。

## 边界

- 本插件只读，不批准、拒绝、发送、执行、部署、删除或扩大监听范围。
- 工具返回“已配置”不等于执行成功；真实结果必须以运行证据和目标回读为准。
- 不把任务正文、人员、项目或能力信息带入与当前请求无关的回答。
- 本机管理服务不可用时明确说明，不用旧结果替代当前状态。
