日期：2026-08-20

候选版本：Foursday `0.6.0` 提交候选
结论：**代码与离线验证已到提交前审阅门禁；生产保持主动安全停机，尚未运行本候选的真实 shadow、active 或回退演练。**

## 1. 本次架构结果

Foursday 已从“自研 Agent Runtime / Hermes 核心补丁”迁移为：

```text
官方固定 Hermes Runtime
+ 原生 foursday Profile
+ 1 个组合插件 / 4 个 Profile 内组件
+ DWS 个人钉钉宿主侧车
+ 个人 default gbrain 读桥与候选晋升
+ 项目路由与高风险 Hook
+ 本机管理台、健康和告警
```

原生路径不修改 Hermes `gateway/session.py`、`gateway/platforms/base.py`、`gateway/run.py` 或其他核心文件。项目和请求人只在单轮 `ContextVar` 中绑定，工具调用由 `pre_tool_call` Hook 固定到已注册项目，退出后清空上下文。

- PostgreSQL 全局暂停：`true`。
- 自管 Gateway 与原生 Gateway：`stopped + disabled`。
- listener、worker、executor、proactive、记忆同步、对账、告警、备份：`stopped + disabled`。
- 生产配置与原生 Profile 本地配置：能力集合为空；发送、群聊、追问、移动审批、个人记忆读取、个人记忆写入和自动确认全部为 `false`。
- 原生 Profile：已安装，`shadow/send=false`，未运行。
- 当前本机 Profile 来自提交前安装，`foursdayCommit=null`；即使提供旧验收回执，active 核心也会拒绝。提交后必须重新安装精确提交才能生成有效身份。
- 只保留本机管理台与只读健康服务。
