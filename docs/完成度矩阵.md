## 统一上线顺序

```mermaid
flowchart LR
    A["填写独立生产配置"] --> B["只读迁移预检"]
    B --> C["加密备份"]
    C --> D["显式数据库迁移"]
    D --> E["严格只读诊断"]
    E --> F["合成 Codex 草稿探针"]
    F --> G["安装或更新服务"]
    G --> H["目标版本服务部署验证"]
    H --> I["严格业务就绪与影子验收"]
    I --> J["人工质量和长期 SLO 门槛"]
    J --> K["另行审批放量"]
```

任何一步失败都停止后续步骤。检查不能暗中迁移，迁移不能暗中部署，部署不能自动打开发送或计划执行。
