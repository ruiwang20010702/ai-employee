## 可靠性与安全证据

- 3 秒安静窗口、8 秒总上限合并短连续消息；更晚消息复用 Session。
- 消息 ID、收件人、活动会话和接管状态以 `600` 检查点跨重启恢复。
- 本人手工回复转换为 `human_takeover` 并触发 Hermes interrupt。
- 撤回只产生不含正文的审计事件。
- 发送必须回读服务器消息 ID；DWS 将换行压平成空格时采用规范化精确正文回读。缺失时 `outcomeUnknown=true` 且不可自动重试；本次第一次前置参数错误确认零发送，第二次结果未知后也未重试，独立回读确认实际仅 1 条。
- 高风险 Hook 阻止 push、merge、release、部署、生产 SQL、不可恢复删除、系统控制、付款、合同、人事和秘密访问。
- Hook 自身配置或 profile 失败时返回 block，不失败开放。
- 终端子进程无网络；Web 出站疑似凭据被拒绝；DWS 出站秘密或不可撤销承诺在桥接前被拒绝。
