# AI 员工验收报告

## 1. 验收结论

截至 2026 年 8 月 5 日，AI 员工的生产底座、钉钉消息监听、草稿生成、人工审批、项目能力网关、正式记忆、运行监控、备份恢复和复用初始化均已完成技术验收。

当前保持“影子运行”：可以监听、判断、生成草稿和形成受控工作计划，但自动发送和计划自动执行没有开启。原因不是系统故障，而是真实人工标注尚未达到放量门槛。

## 3. 尚未达到的放量条件

| 条件 | 当前状态 | 处理方式 |
|---|---|---|
| 100 条真实人工判断标注 | 0/100 | 在管理台“判断质量”按风险与覆盖队列人工标注，禁止 AI 自己补标签 |
| 分层覆盖 | 尚未达到 | 同时覆盖回复/不回复、私聊/群聊、硬规则/Codex/人工复查来源 |
| 不回复准确率 ≥ 95% | 样本不足 | 满足样本与覆盖后再计算 |
| 高风险错误回复建议为 0 | 尚无充分样本 | 发现一条即阻止放量 |
| 滚动 30 天入口可用性 ≥ 99.5% | 观察窗口未满 | 系统持续分钟采样，满窗口前 `targetMet` 保持未知 |

## 4. 复用验收流程

```mermaid
flowchart LR
    A[克隆代码并安装依赖] --> B[生成受保护的生产配置]
    B --> C[创建项目能力清单]
    C --> D[只读生产诊断]
    D --> E[加密备份并迁移数据库]
    E --> F[安装 9 个常驻服务]
    F --> G[生产健康与真实消息对账]
    G --> H[影子人工标注]
    H --> I[满足门槛后单独审批放量]
```

新环境必须使用自己的租户、联系人、项目目录、数据库、密钥和审批人。示例配置只说明结构，不构成任何真实权限。生产发布工作流在迁移前强制执行加密备份，任何预检、备份、迁移或验证失败都会停止后续步骤。

## 5. 验收边界

- 本报告不把“进程启动”当作业务放量，也不把短期可用性观察值当作月度达标。
- OA 审批同意、拒绝、转交以及通用生产数据修改仍属于禁止自动执行能力。
- 自动发送和计划自动执行保持关闭；开启必须另有明确授权，并满足影子质量和真实项目清单门槛。
- Codex CLI 最近一次只读诊断已通过运行校验；版本检查存在非阻断告警。生产健康检查不代替真实草稿质量验收，放量前仍应重新运行真实草稿探针。
