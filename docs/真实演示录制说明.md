# 75 秒真实演示录制说明

v0.5 的公开演示必须来自同一次真实闭环，不能把本地预览、无关 PR 和模拟结果剪接成“已完成”。英文[录制契约与分镜](./en/demo.md)是默认公开版本，中文统一口径如下：

1. 使用公开、合成内容的 GitHub Issue 和干净候选提交。
2. 先展示五步预览与 `0 external systems touched`，再创建本地加密会话。
3. 清楚展示完整计划哈希、一次性审批及“不能合并、不能部署”。
4. 连续展示补丁、隔离分支、登记测试、受限推送、Draft PR 逐字段回读。
5. 打开同一个 Draft PR，核对草稿状态、分支、提交、标题、基础分支与测试。
6. 最后分别确认项目记忆候选和时间返还，不把模型估算自动计入结果。
7. 确认后下载证据包，展示 `verified_closed_loop` 和完整性摘要。
8. 结尾保留候选 SHA、公开 Issue/PR、运行时、测试结果和“未合并、未部署、生产发送仍关闭”。

只有第二个人依据 Quick Start 复现成功后，才能把它表述为“真实演示视频”；在此之前统一称为录制计划。
