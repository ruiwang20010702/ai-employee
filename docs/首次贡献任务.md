# 首次贡献任务

Foursday 的首批 `good first issue` 聚焦“让陌生用户更容易完成前十分钟”，同时避开生产发送、计划放量、凭据、部署和新增外部写入。英文[首次贡献入口](./en/first-contributions.md)是对外默认清单，下面是中文口径：

| 编号 | 用户结果 | 主要范围 |
|---|---|---|
| GFI-001 | 可复制完整计划哈希，并向键盘与读屏用户反馈成功 | Web 接入页 |
| GFI-002 | 对常见接入失败提供不泄露本机信息的修复指引 | Web 接入页与文档 |
| GFI-003 | 增加一个无凭据、无外部副作用的社区配方示例 | 配方示例 |
| GFI-004 | 覆盖一个 OpenAI-compatible 提供方边界用例 | 提供方契约测试 |
| GFI-005 | 增加可重复的手机端接入页视觉检查 | 贡献者工具 |

这些内容目前是随 v0.5 候选提交的 Issue 草案；推送候选版后才会发布为真实 GitHub Issue。在真实 Issue 发布前，不宣称任务已经开放领取。
