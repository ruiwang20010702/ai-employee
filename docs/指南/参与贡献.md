# 参与贡献

Foursday 是只有一个 Codex Agent Loop 的工作分身产品。贡献应增强连接器、规则、Skill、MCP、项目路由、个人记忆、DWS、隔离、回读和恢复能力，不要重新实现另一套 Agent Runtime。

```bash
npm ci
npm run check:full
npm run check:security
git diff --check
```

不要提交 `.runtime/`、凭据、真实消息、个人标识、数据库导出、私人 gbrain 页面或本机绝对路径。行为改动应覆盖允许、拒绝、失败、重复、重启和最终回读。

任何用户可见行为变更都必须对应[产品需求文档](../产品需求文档.md)中的既有需求或验收场景。如果尚无对应条目，应先更新 PRD，再在同一个变更中同步技术设计、公开说明和实现。

不要新增业务专用 capability manifest、JSON Pointer、固定回复模板、第二套知识库、第二套 Agent Loop 或控制平面核心补丁。
