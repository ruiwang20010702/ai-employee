# 集成扩展指南

新增能力时优先选择最小的 Foursday 扩展面，发行层在内部把这些契约映射到内嵌控制平面：

| 需求 | 扩展方式 |
|---|---|
| 新消息平台 | Foursday connector |
| 项目发现或上下文 | Profile plugin / Hook |
| 可重复工作方法 | Skill |
| 外部应用 API | MCP server 或 tool plugin |
| 外部或不可逆动作 | 负责人独立授权出口 |

不要新增 capability manifest、业务专用 JSON 指针、固定回复模板、第二套 Agent Loop 或控制平面核心补丁。

任何集成都必须保留身份绑定、项目隔离、秘密隔离、人工接管、幂等、未知结果处理和精确回读，并覆盖成功、拒绝、错配、重试、重启与重复输入测试。

当前实现示例见 `distribution/plugins/` 与 `distribution/skills/`。
